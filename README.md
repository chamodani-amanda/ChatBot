# 🤖 ChatBot – Rule-Based AI Assistant

This project is developed as **Project 1: Rule-Based AI Chatbot** for the DecodeLabs Artificial Intelligence internship.

According to the project requirement, the goal is to create a simple chatbot that responds to predefined user inputs using rule-based logic.

---

## 📌 Project Objective

The main objective of this project is to build a chatbot that can:

- Handle greetings
- Respond to predefined questions
- Use rule-based decision-making logic
- Run as a continuous chat system
- Provide a simple AI-style user interaction

---

## 🚀 Features

- Professional web-based chatbot interface
- Rule-based response system
- Predefined question-answer handling
- Keyword-based response support
- Fuzzy matching for simple typing mistakes
- Enter key support for sending messages
- Flask backend
- HTML, CSS, and JavaScript frontend

## 🧠 How It Works

The chatbot takes user input, cleans the text, checks it with predefined rules, and returns the most suitable response.

Basic workflow:

```
User Input → Text Cleaning → Rule Matching → Bot Response
```
